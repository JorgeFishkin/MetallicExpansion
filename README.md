# Metallic Expansion
Metallic Expansion is a Minecraft mod for Forge aiming to add more real-world metals to Minecraft. Each metal has its own armor and toolset.

The mod uses Forge tags for each of the metals, so it will fit nicely with any mod that makes use of them (Alchemsitry, Mekanism, etc.) It is recommended to use JAOPCA to add further compatability, as well as a unifier like Almost Unified.
